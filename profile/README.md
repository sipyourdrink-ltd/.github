### [Bernstein](https://github.com/sipyourdrink-ltd/bernstein) &nbsp;·&nbsp; open source

Deterministic orchestrator for 30+ CLI AI coding agents. One isolated git worktree per task and no model in the coordination loop, so a parallel run replays byte-for-byte. Signed lineage, quality gates, MCP server mode. Apache-2.0.
